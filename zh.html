01

開始使用

這是編輯 VRChat Expression Menu 與 Parameters 的 Unity Editor 工具。先讀取 Avatar，再選擇適合的模式。

請在已安裝 VRChat SDK Avatars 的 Unity 專案使用。MA 模式另需支援的 Modular Avatar 與 NDMF。

  1. 匯入套件

    解壓從 BOOTH 取得的 ZIP，匯入 unitypackage。操作前可先備份場景或專案。

  2. 開啟工具

    從 Unity 上方「黒猫Dev → メニューエディ」開啟。指定 Avatar 根物件，或在 Hierarchy 選取後按「使用目前選取」。

  3. 讀取並選擇模式

    按「讀取」取得資料。偵測到啟用的 MA Menu Installer 等來源時，可能預設顯示合併模式；可用上方三個分頁切換。

02

如何選擇模式

最重要的是「讀什麼、存到哪裡」。依照要保留來源還是直接更改，選擇模式。

模式用途保存位置與來源影響
編輯並保存副本編輯基礎 Menu／Parameters；搜尋、多選、排序、移動與分組。保留來源

保存至專用副本，保留原始 Menu／Parameters；不包含 MA 新增項目。

MA 合併後整理整理基礎＋MA 合併結果，支援排序、移動、分組與圖示規則。保存規則

將整理規則存於 Avatar，建置時套用；保留原始 Menu 與 MA 設定。

MA 來源圖示（快速）不執行合併，直接替換 MA Menu Installer／MA Menu Item 的來源圖示。直接更改來源

直接修改來源 Menu／元件；共用 Menu 的其他 Avatar 也會受影響。

副本模式找不到 MA 項目時，請切換「MA 合併後整理」。有些 SubMenu 在來源中是空的，內容會在建置時才由 MA 加入。

05

保存與復原

每個模式的「保存」方式不同；完成編輯不代表所有結果已經保存。

副本編輯

按「儲存副本」輸出至 Assets/MenuEditor/Generated。勾選指定給 Avatar 時，Avatar 的參照也會改變，請另存場景／Prefab。保存失敗會保留編輯內容並顯示原因。

MA 整理

先按「將規則保存到 Avatar」，再存場景／Prefab。移除 Menu Organization 元件可停止套用規則，恢復原生成方式；設定元件會從建置結果移除。移除整理元件不會復原來源圖示模式直接做的修改。

來源圖示

Menu 資產會直接更新並立即保存；元件變更需保存場景／Prefab。本 Avatar 規則只在能唯一對應時更新；其他 Avatar 的共用來源規則要另行檢查。

Undo／Redo

一次批次操作可完整 Undo／Redo。工具視窗取得焦點後使用 Unity 的復原／重做；副本模式不會為了復原工作資料而改寫來源。

移動前檢查

  • 目的地超過 8 項，或把 SubMenu 移入自身／後代時會拒絕；整批取消，不允許部分成功。
  • 共用 SubMenu 維持同一資產的共用語意，不會擅自複製成獨立選單。
  • 重載或切換 Avatar 時不沿用失效選取；保存前請確認正在操作的對象。
06

常見問題

遇到問題時，先確認目前模式與 Console 第一則訊息。

MA 項目沒顯示，或 SubMenu 是空的

副本模式只讀基礎 Menu。請切換「MA 合併後整理」並重讀；若有依賴或版本提示，請確認下方支援組合。來源圖示清單並非合併後最終排列。

圖示或 Toggle 與遊戲內顯示不同

未指定圖片時，VRChat 會使用自己的預設圖。本工具顯示 Control 類型，不模擬 Toggle 開關或 Puppet 即時值。MA 合併模式讀回 NDMF 完成時結果，不涵蓋 NDMF 以外更晚的 VRCFury／SDK／VRChat 處理。

「指定圖片」與「NDMF 最終預覽」不同

指定圖片是規則保存的資產，最終預覽是完整 NDMF 處理後輸出。後段工具或生成時的尺寸與壓縮處理可能造成差異；若結構變更而無法可靠對應，會顯示原因並停止。

修改來源後，整理規則失效了

來源刪除、改名或對應有歧義時，不會猜測套用到其他項目。請重讀、清除失效規則後重設；若不需要整理，可移除 Avatar 根物件上的 Menu Organization 並保存場景／Prefab。

超過 256 bits，但會用 VRCFury 壓縮

顯示的是壓縮前用量。副本模式可明確勾選「交由建置階段處理參數預算」，僅將超量改為警告以允許保存；此選項不執行壓縮，其他錯誤仍會阻擋。切換 Avatar 或重讀會重設關閉，最終容量需由實際建置確認。

Expression Parameters 與 Animator 型別不一致

核對診斷中的參數名稱及 Expression Parameters／FX Animator 型別。有些配置會在建置時生成或轉換，因此工具不會只因警告就自動轉型或刪除；確認預期開關或數值含義後再修正，並檢查建置結果。

無法移動，或目的地超過 8 項

確認目的地數量與循環參照。工具不會自動刪除或默默分頁；請改選其他 SubMenu，或先整理部分項目再操作。

沒有 MA／NDMF 還能使用嗎

可以。已安裝 VRChat SDK 時仍可使用副本模式；MA 模式會顯示依賴提示。如果移除依賴後 Avatar 上還有整理規則，請恢復支援組合或移除整理元件。

處理可能超過 5 秒嗎

測試案例以單次 5 秒內為門檻，但不保證所有 Avatar 或電腦。完整合併也會執行其他 NDMF 處理；請查看 UI 耗時與原因，僅換圖時可選擇來源模式。

也能修好 MA 的 Burst 或 Inspector 錯誤嗎

工具的合併預覽會僅在處理期間暫停 Burst，結束後還原。這不代表能一併修好 MA 自身 Inspector、Play Mode 或 SDK 建置錯誤；請從 Console 第一個原因檢查。

沒有符合的問題，請縮短搜尋文字。

若仍無法解決，請附上 Unity／SDK／MA／NDMF 版本、目前模式及 Console 第一則訊息，透過 BOOTH 聯絡。 BOOTH ↗
