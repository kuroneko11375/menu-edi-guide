01

はじめに

VRChat の Expression Menu と Parameters を編集する Unity Editor ツールです。まず Avatar を読み込み、目的に合うモードを選びます。

VRChat SDK Avatars が入った Unity プロジェクトで使用します。MA 用モードには、対応する Modular Avatar と NDMF が必要です。

  1. パッケージをインポート

    BOOTH から取得した ZIP を展開し、unitypackage をインポートします。作業前に、シーンやプロジェクトのバックアップを残しておきましょう。

  2. ウィンドウを開く

    Unity 上部の「黒猫Dev → メニューエディ」を開きます。Avatar のルートを指定するか、Hierarchy で選んで「選択中を使用」を押します。

  3. 読み込んで、モードを選ぶ

    「読み込む」でデータを取得します。有効な MA Menu Installer などを検出すると、合成モードが初期表示される場合があります。上部の 3 つのタブで切り替えられます。

02

モードの選び方

一番大切なのは「何を読み、どこへ保存するか」。元の設定を残したいか、直接変更したいかで選びます。

モードできること保存先・元データへの影響
編集・コピーを保存ベース Menu・Parameters の編集。検索、複数選択、並べ替え、移動、グループ化。元データを保持

専用コピーに保存。元の Menu／Parameters を保持。MA の追加項目は含みません。

MA 合成後の整理ベース＋MA の合成結果を並べ替え、移動、グループ化。アイコンのルールも設定できます。ルールを保存

Avatar に整理ルールを保存。ビルド時に適用。元の Menu・MA 設定は保持。

MA 参照元アイコン（高速）合成処理をせず、MA Menu Installer／MA Menu Item の参照元アイコンを変更。元データを変更

元の Menu／コンポーネントを直接変更。共有 Menu は、ほかの Avatar にも影響。

コピー編集で MA の項目が見つからないときは、MA 合成後の整理へ切り替えてください。空の SubMenu に見えても、ビルド時に MA が内容を追加する構成があります。

05

保存と元に戻す

操作後の「保存」は、モードによって異なります。作業データの変更だけでは、すべての結果が保存されたことにはなりません。

コピー編集

「コピーを保存」で Assets/MenuEditor/Generated に出力します。割り当てを有効にした場合は Avatar の参照先も変わるため、シーン／Prefab も保存してください。失敗時は編集内容を保持し、理由を表示します。

MA の整理

「ルールを Avatar に保存」してから、シーン／Prefab を保存します。Menu Organization を外すと整理ルールの適用をやめ、元の生成方法に戻ります。設定コンポーネントはビルド結果から除去されます。参照元アイコンの直接変更は、整理コンポーネントを外しても戻りません。

参照元アイコン

Menu アセットは直接更新・即時保存。コンポーネント変更はシーン／Prefab の保存が必要です。本 Avatar のルールは一意に対応できた場合のみ追従します。他の Avatar の共有元ルールは別途確認してください。

Undo／Redo

一括操作は 1 回の Undo／Redo で扱います。メニューエディにフォーカスした状態で Unity の Undo／Redo を使います。コピー編集の未保存データを戻すために、元アセットを書き換えることはありません。

移動前に確認すること

  • 目的地が 8 項目を超える移動や、SubMenu を自身・子孫に移す操作は拒否します。問題がある場合は一括で中止し、一部だけ移しません。
  • 共有 SubMenu は、同じアセットの共有を維持します。別の場所からも参照されるため、勝手に独立コピーにはしません。
  • 再読み込み・Avatar 切替では無効な選択を持ち越しません。保存前に作業対象を再確認してください。
06

よくある質問

困ったときは、いま選んでいるモードと Console の最初のメッセージを確認してください。

MA の項目が表示されない／SubMenu が空です

コピー編集はベース Menu のみです。「MA 合成後の整理」に切り替えて再読み込みます。依存関係やバージョンの案内が出る場合は、下記の対応構成を確認してください。参照元アイコンの一覧は、合成後の最終配置ではありません。

ゲーム内のアイコンや Toggle と、見え方が違います

画像未指定の場合、VRChat は独自の既定画像を表示します。本ツールは Control 型を表示し、Toggle の ON/OFF や Puppet 値をシミュレートしません。MA 合成モードは NDMF 完了時点を読み戻しますが、NDMF 外の後続 VRCFury／SDK／VRChat 処理は含みません。

「指定画像」と「NDMF 最終プレビュー」が違います

指定画像はルールに保存する資産、最終プレビューは全 NDMF 処理後の出力です。後段のツールによる変更や生成時のサイズ・圧縮処理で異なる場合があります。後段で構造が変わり対応を特定できない場合は、理由を表示して停止します。

参照元を変更したら、ルールが無効になりました

削除・改名・曖昧な対応を、別項目への推測適用で補いません。再読み込みし、無効なルールをクリアして設定し直します。整理を使わない場合は Avatar ルートの Menu Organization を外し、シーン／Prefab を保存してください。

256 bits を超えています。VRCFury で圧縮する予定です

表示値は圧縮前です。コピー編集の「Parameter 予算をビルド時に処理する」を明示的に有効にすると、容量超過だけを警告として保存できます。圧縮を実行する設定ではなく、他のエラーは保存を止めます。Avatar 切替・再読み込みでオフに戻ります。最終容量は実際のビルドで確認してください。

Expression Parameters と Animator の型に違いがあります

診断に表示された Parameter 名と、Expression Parameters／FX Animator の型を確認します。ビルド時に生成・変換する構成もあるため、警告だけで自動変換・削除はしません。期待する ON/OFF や数値の意味を確認してから修正し、最終動作は実際のビルドで確認してください。

移動できない／8 項目を超えます

移動先の項目数と循環参照を確認します。不要なものを自動削除したり、勝手にページ分割したりはしません。別の SubMenu を選ぶ、先に一部を整理するなどしてからやり直してください。

MA／NDMF を入れていない場合も使えますか

はい。VRChat SDK がある環境で、コピー編集を利用できます。MA 用モードは対応する依存関係を案内します。Avatar に整理ルールが残った状態で依存関係を外した場合は、対応構成を戻すか、整理コンポーネントを外してください。

処理が 5 秒を超えることはありますか

検証用ケースは 1 回 5 秒以内を基準にしていますが、すべての Avatar や PC の保証ではありません。完全合成では他の NDMF 処理も実行します。UI の所要時間と理由を確認し、画像だけの変更なら参照元モードも選べます。

MA の Burst／Inspector エラーも直せますか

本ツールの合成プレビューでは、処理中のみ Burst を一時停止し、終了時に元へ戻す互換処理があります。MA 自身の Inspector、Play Mode、SDK ビルドのエラーを一括修復する機能ではありません。Console の最初の原因を確認してください。

一致する質問がありません。検索語を短くしてみてください。

解決しない場合は、Unity／SDK／MA／NDMF のバージョン、選択したモード、最初の Console メッセージを添えて、BOOTH からお問い合わせください。 BOOTH ↗

プレビューと実機の違いUnity のコンパイル、EditMode、保存・再読込、テスト Avatar の NDMF、クリーン package の導入を確認しています。個別 Avatar の VRChat Build & Test、アップロード、ゲーム内・VR 機器の動作は未確認です。Windows のアイコン生成は DXT5 で確認し、Android／iOS の ASTC は未検証です。
